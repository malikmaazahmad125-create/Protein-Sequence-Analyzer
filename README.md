# 🧬 **PROTEIN SEQUENCE ANALYZER**

A Python-based **Protein Sequence Analyzer** designed to analyze protein sequences and extract meaningful biological insights using **Python, NumPy, Pandas, Matplotlib, and Seaborn**.

This project demonstrates how programming and data analysis techniques can be applied to biological protein sequences.

---

## 🚀 **FEATURES**

* ✅ **Protein Sequence Validation**
* 🧬 **Amino Acid Counting**
* 🔢 **Dictionary-Based Analysis**
* 📊 **Protein Sequence Statistics**
* 🧮 **NumPy Array Operations**
* 📈 **Mean, Median & Standard Deviation**
* 🔍 **Most Common Amino Acid Detection**
* 🔍 **Least Common Amino Acid Detection**
* 📋 **Pandas DataFrame Analysis**
* 📊 **Amino Acid Percentage Calculation**
* 🔎 **Filtering Non-Zero Amino Acids**
* 📈 **Data Visualization Support**
* 📄 **Complete Final Protein Analysis Report**

```text
MKWVTFISLLFLFSSAYSRGVFRRDTHKSEIAHRFKDLGE
```

---

## 📊 **ANALYSIS PERFORMED**

1. **Validates the protein sequence**
2. **Checks for valid amino acids**
3. **Counts all amino acids**
4. **Calculates total sequence length**
5. **Finds unique amino acids**
6. **Identifies the most common amino acid**
7. **Identifies the least common amino acid**
8. **Converts amino acid counts into a NumPy array**
9. **Calculates Mean**
10. **Calculates Median**
11. **Calculates Standard Deviation**
12. **Finds Minimum and Maximum values**
13. **Creates a Pandas DataFrame**
14. **Calculates amino acid percentages**
15. **Filters amino acids with counts greater than zero**
16. **Generates statistical insights**
17. **Displays the final protein sequence analysis report**
